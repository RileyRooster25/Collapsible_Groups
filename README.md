# Collapsible Groups

Organize items, fluids, and other ingredients into collapsible groups in Minecraft 1.21.1.

Use built-in groups or create your own with the in-game editor, JSON files, resource packs, or KubeJS. Manage, search, and enable groups from one screen.

Supports JEI on Fabric, Forge, and NeoForge, with EMI support on Fabric and NeoForge.

**Compatibility:** Requires Java 21. JEI integration requires JEI 19.64.0.454 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.21.1 or newer remains supported on Fabric and NeoForge. Use Forge 52.0.28+, NeoForge 21.1.238+, or Fabric Loader 0.16.9+ with Fabric API 0.116.17+1.21.1 or newer.

## Build requirements

Run Gradle with JDK 25. The Java toolchain still targets Java 21 for Minecraft.
