# Collapsible Groups

Organize items, fluids, and other ingredients into collapsible groups in Minecraft 26.1.2.

Use built-in groups or create your own with the in-game editor, JSON files, resource packs, or KubeJS. Manage, search, and enable groups from one screen.

**Compatibility:** Requires Java 25 and JEI 29.47.0.110 or newer. Older JEI versions are no longer supported. Use NeoForge 26.1.2.99+, or Fabric Loader 0.19.5+ with Fabric API 0.155.3+26.1.2 or newer. EMI is not supported in this Minecraft version.

EMI has no published 26.1.2 artifact and is not enabled in this build.

## Build requirements

Run Gradle with JDK 25. The Java toolchain still targets Java 25 for Minecraft.
