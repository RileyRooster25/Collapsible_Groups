# Collapsible Groups

Organize items, fluids, and other ingredients into collapsible groups in Minecraft 1.20.1.

Use built-in groups or create your own with the in-game editor, JSON files, resource packs, or KubeJS. Manage, search, and enable groups from one screen.

Supports JEI and EMI on Fabric and Forge.

**Compatibility:** Requires Java 17. JEI integration requires JEI 15.71.0.223 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.20.1 or newer remains supported. Use Forge 47.4.10+, or Fabric Loader 0.19.5+ with Fabric API 0.92.11+1.20.1 or newer.

## Build requirements

Run Gradle with JDK 25. The Java toolchain still targets Java 17 for Minecraft.
