# Collapsible Groups 2.0.0-beta4.1 — Minecraft 1.20.1

- Updated compatibility for JEI 15.74.0.225.
- Fixed a startup crash caused by changes to JEI's input handler.
- Fixed JEI search-field crashes on Forge.
- Added Simplified Chinese translations, contributed by OnlySole.

**Compatibility:** Requires Java 17. JEI integration requires JEI 15.74.0.225 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.20.1 or newer remains supported. Use Forge 47.4.10+, or Fabric Loader 0.19.5+ with Fabric API 0.92.11+1.20.1 or newer.
