# Collapsible Groups 2.0.0-beta4 — Minecraft 1.20.1

- Updated compatibility for JEI 15.71.0.223.
- Fixed group expansion, collapse, and manager button input with newer JEI releases.
- The group manager button now stays available when a search has no results.
- Search matching now follows JEI's active language.
- Fixed stale search results after changing JEI filter or sorting settings.

**Compatibility:** Requires Java 17. JEI integration requires JEI 15.71.0.223 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.20.1 or newer remains supported. Use Forge 47.4.10+, or Fabric Loader 0.19.5+ with Fabric API 0.92.11+1.20.1 or newer.
