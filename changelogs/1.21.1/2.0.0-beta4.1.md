# Collapsible Groups 2.0.0-beta4.1 — Minecraft 1.21.1

- Updated compatibility for JEI 19.69.0.456.
- Fixed a startup crash caused by changes to JEI's input handler.
- Added Simplified Chinese translations, contributed by OnlySole.

**Compatibility:** Requires Java 21. JEI integration requires JEI 19.69.0.456 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.21.1 or newer remains supported on Fabric and NeoForge. Use Forge 52.0.28+, NeoForge 21.1.238+, or Fabric Loader 0.16.9+ with Fabric API 0.116.17+1.21.1 or newer.
