# Collapsible Groups 2.0.0-beta5 — Minecraft 1.21.1

- Reduced JEI search stalls by reusing ingredient data until the source changes.
- Improved rendering performance on pages with many group headers.
- Improved rendering of expanded EMI groups and reduced repeated work when using multiple item-index sidebars.

**Compatibility:** Requires Java 21. JEI integration requires JEI 19.69.0.456 or newer; older JEI versions are no longer supported. EMI 1.1.24+1.21.1 or newer remains supported on Fabric and NeoForge. Use Forge 52.0.28+, NeoForge 21.1.238+, or Fabric Loader 0.16.9+ with Fabric API 0.116.17+1.21.1 or newer.
