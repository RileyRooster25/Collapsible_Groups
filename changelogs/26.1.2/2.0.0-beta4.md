# Collapsible Groups 2.0.0-beta4 — Minecraft 26.1.2

- Updated compatibility for JEI 29.47.0.110.
- Fixed group expansion, collapse, and manager button input with newer JEI releases.
- The group manager button now stays available when a search has no results.
- Search matching now follows JEI's active language.

**Compatibility:** Requires Java 25 and JEI 29.47.0.110 or newer. Older JEI versions are no longer supported. Use NeoForge 26.1.2.99+, or Fabric Loader 0.19.5+ with Fabric API 0.155.3+26.1.2 or newer. EMI is not supported in this Minecraft version.
